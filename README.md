# بطاقات AT — التكرار المتباعد

تطبيق Flutter عربي للمراجعة بالبطاقات والتكرار المتباعد.

## الميزات
- واجهة عربية.
- إنشاء بطاقات يدويًا ومجموعات.
- جدولة مراجعة بأربعة تقييمات.
- حفظ البطاقات والتقدم محليًا.
- إحصائيات.
- اختيار PDF وإرساله إلى API عند إعدادها.

## بناء APK
كل push إلى main يشغّل GitHub Actions. افتح تبويب Actions ثم آخر تشغيل وحمّل artifact باسم at-cards-apk.

## تحويل PDF بالذكاء الاصطناعي
ميزة تحويل PDF تحتاج خدمة API ترجع JSON بالشكل {"cards":[{"front":"السؤال","back":"الجواب"}]}. مرّر رابطها عند البناء عبر --dart-define=CARDS_API_URL=https://your-service.example/api. لم يتم تضمين خدمة خلفية أو مفتاح API.
