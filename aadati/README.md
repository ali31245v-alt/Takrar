# عاداتي — تطبيق تنظيم العادات

تطبيق Flutter عربي بواجهة داكنة عصرية باللون الكحلي والبنفسجي والسماوي.

- لوحة رئيسية تعرض إنجاز اليوم ونسبة التقدم.
- إضافة العادات وحذفها بالضغط المطوّل.
- تحديد العادات المكتملة.
- صفحة إحصائيات وحساب.
- حفظ محلي للعادات باستخدام SharedPreferences.
- واجهة عربية من اليمين إلى اليسار.

## بناء APK
شغّل GitHub Actions ثم حمّل artifact باسم `aadati-debug-apk`. التذكيرات المجدولة ليست مفعّلة بعد، ويجب اختبار البناء والـ APK قبل الإصدار النهائي.
